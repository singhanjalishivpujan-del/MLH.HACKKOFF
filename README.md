# MLH.HACKKOFF
Multimodal Visual QA: Upload flowcharts, UI mockups, handwritten notes, or error tracebacks to receive structured explanations, root-cause analyses, and action steps.
Lightweight & Rapid Prototyping: Uses Google's open-weights Gemma 4 model with high throughput and low resource overhead.
Structured JSON Extraction: Extract tabular data, API contracts, and key-value attributes from raw images or documents into verified JSON schemas.
Open-Source Model Harness: Pluggable architecture designed to run against the Gemini API endpoint or swap to local open-weight runtimes (such as Ollama or Hugging Face).
Interactive Streamlit Workspace: Clean, responsive web UI for instant testing, prompt tuning, and document uploads.
